# Isaac Transformer and Single Stage

Outil HTML (transformateur/DAB, dans `www/index.html`), empaqueté en application Android via Capacitor.

## Récupérer l'APK
Après chaque push sur `main` (ou en relançant manuellement l'onglet **Actions** de ce dépôt), l'APK de débogage est produit par le flux « Build APK » et disponible en téléchargement dans l'onglet **Actions → (dernier run) → Artifacts**.

## Mettre à jour l'outil
Remplacer `www/index.html` par la nouvelle version et pousser sur `main` : la compilation se relance automatiquement.
